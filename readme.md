# Projet de jeu Capitalisme

## Organisation

- `jeu/` : version orientée objet du jeu et ses modules.
- `ancien_prototype/` : ancienne version et scripts de génération.
- `tests/` : scripts de test et d’expérimentation.
- `.sauvegarde/` : fichiers de sauvegarde locaux.
- `.git/` : métadonnées et historique du dépôt Git (géré automatiquement par Git).

## Lancer le jeu

Depuis la racine du projet, lancez :

```powershell
python -m jeu.capitalisme_poo
```

Les chemins de sauvegarde sont relatifs à la racine du projet ; lancez donc le jeu depuis ce dossier.
